# AGENTS.md — Стандарты разработки и протоколы для ИИ

Этот документ определяет строгие инженерные стандарты, соглашения об именовании, правила безопасности и протоколы валидации для любого ИИ-агента или инженера, создающего или модифицирующего моды для **Minecraft: Java Edition**.

---

## 1. Фундаментальные принципы (Core Philosophy)

1. **Строгая независимость модулей (Zero Unnecessary Coupling):**
   - Модули совместимости со сторонними модами обязаны быть автономными (`@Pseudo`, `require = 0`, soft-reflection). Мод обязан собираться и работать, даже если целевой сторонний мод отсутствует.
2. **Безопасность сетевого и серверного окружения:**
   - Никаких вызовов классов `net.minecraft.client.*` на выделенном сервере.
   - Миксины с модификацией серверной логики размещаются в общем массиве `"mixins": [...]`, а не в `"server": [...]` (так как `"server"` игнорируется в одиночной игре).
3. **Чистота и детерминированность версий:**
   - Внутри мода (`gradle.properties`, манифесты `fabric.mod.json`, `neoforge.mods.toml`) версия стандартизирована строго в формате SemVer без префикса `v` (например, `1.0.0` или `1.1`).
   - Префикс `v` разрешен только в финальных именах файлов (`-v1.1.jar`).
4. **Стандарт одиночного артефакта (Single Output):**
   - При сборке мода создается только чистый готовый к установке JAR. Лишние таски (`sourcesJar`, `javadocJar`) отключаются.

## 2. Архитектурные правила по версиям Minecraft

### Minecraft 1.21.4:
- **Client Item Definitions:** Модели предметов загружаются через `assets/<namespace>/items/<id>.json`.
- **RegistryKey NPE Guard:** Все `Item.Settings` и `AbstractBlock.Settings` обязаны иметь `.registryKey(key)`. Иначе — мгновенный краш `NullPointerException: Item id not set`.
- **Строгий GZIP для структур:** Файлы NBT структур обязаны быть сжаты GZIP (`1F 8B`) и размещены в `data/<namespace>/structure/` (в единственном числе!).
- **EntityRenderState:** Рендеринг сущностей переведен на состояние `RenderState` (например `BipedEntityRenderState`).

### Minecraft 26.x:
- **Java 25 LTS:** Требуется компилятор и рантайм Java 25.
- **SDL3 Модель ввода:** Кнопки мыши 1-based (`InputConstants.MOUSE_BUTTON_LEFT = 1`, `RIGHT = 3`, `MIDDLE = 2`).
- **Title Screen Registry Guard:** Инициализаторы компонентов предметов (`BuiltInRegistries.DATA_COMPONENT_INITIALIZERS.build()`) требуют защитную обертку `safeProvider` при открытии GUI из главного меню.

## 3. Чек-лист проверки перед коммитом (Verification Checklist)

- [ ] Код компилируется без ошибок (`./gradlew build` -> `BUILD SUCCESSFUL`).
- [ ] Все вызовы идентификаторов используют `Identifier.of(...)` (Fabric) или `ResourceLocation.fromNamespaceAndPath(...)` (NeoForge).
- [ ] Все JSON файлы соответствуют актуальной спецификации (рецепты со строковыми ID ингредиентов, лут-таблицы с массивом `conditions`).
- [ ] Локализация синхронизирована одновременно в `en_us.json` и `ru_ru.json`.
- [ ] Документация игрока (`README.md`) не содержит технических классов или внутренних терминов.
